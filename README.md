# Todo List

一个简洁、响应式的 Todo List 单页应用，使用原生 HTML、CSS 和 JavaScript 构建，无需安装依赖。

## 功能

- 新增、编辑、完成和删除任务，并为任务设置可选截止日期
- 按全部、待完成、已完成筛选
- 实时搜索任务
- 显示任务完成进度
- 逾期未完成任务会以红色提示
- 使用 `localStorage` 自动保存数据
- 适配桌面端和移动端

## 使用方法

直接在浏览器中打开 `index.html` 即可使用。

也可以在项目目录启动一个本地静态服务器：

```bash
python -m http.server 8000
```

然后访问 <http://localhost:8000>。
